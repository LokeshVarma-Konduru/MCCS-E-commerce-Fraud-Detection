# MCCS E-commerce Fraud Detection API Documentation

## Overview
This document provides comprehensive API documentation for the MCCS E-commerce Fraud Detection system, covering Store Management and Transaction Processing APIs.

## Base URL
```
http://localhost:3000/api
```

## Authentication
Most endpoints require authentication via JWT token or API key. Include the token in the Authorization header:
```
Authorization: Bearer <your-jwt-token>
```
or
```
X-API-Key: <your-api-key>
```

## 2. Get All Transactions
**Endpoint:** `GET /transactions`  
**Description:** Retrieve transactions with filtering, pagination, and search capabilities  
**Authentication:** Required  

### Query Parameters
- `page` (optional): Page number (default: 1)
- `limit` (optional): Items per page (default: 10)
- `model` (optional): Filter by ML model used
- `prediction` (optional): Filter by prediction value (0 or 1)
- `status` (optional): Filter by status (pending, approved, rejected, under_review)
- `userId` (optional): Filter by user ID
- `startDate` (optional): Filter by start date (ISO format)
- `endDate` (optional): Filter by end date (ISO format)
- `productCategory` (optional): Filter by product category
- `paymentMethod` (optional): Filter by payment method
- `transactionType` (optional): Filter by transaction type (online, in-store)
- `minRiskScore` (optional): Minimum risk score filter
- `maxRiskScore` (optional): Maximum risk score filter
- `minAmount` (optional): Minimum transaction amount filter
- `maxAmount` (optional): Maximum transaction amount filter
- `search` (optional): Search across transaction ID, amount, status, type, payment method
- `storeRef` (optional): Filter by store reference (ObjectId)
- `storeID` (optional): Filter by store ID

### Example Request
```
GET /transactions?page=1&limit=20&prediction=1&status=under_review&search=fraud
```

### Response

# REAL-TIME FEATURES

## WebSocket Events

### Fraud Alert Event
When a transaction is predicted as fraudulent, a real-time alert is emitted:

```javascript
// Client-side WebSocket listener
socket.on('fraud_alert', (alertData) => {
  console.log('Fraud detected:', alertData);
});
```

### Alert Data Structure
```json
{
  "type": "fraud_detected",
  "transactionId": "transaction_object_id",
  "transactionIdShort": "TRX-ABC123",
  "amount": 150.00,
  "paymentMethod": "credit_card",
  "productCategory": "electronics",
  "deviceUsed": "mobile",

  "riskLevel": "High",
  "probability": "85.0",
  "modelUsed": "logistic-regression",
```
